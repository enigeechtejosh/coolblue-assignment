# Assignment

In this assignment we would like you to build an amazing web API for a frontend Pets web app. 🧑‍🏭

* The current code is very basic and could do with improvements in many places.
* What we're mostly looking for is to see what you chose to tackle and how you went about it.
* Decide what you think is important to tackle, remember you won't have time to do everything.
* Please make regular git commits while working on the project, so we get a feel for the way in which you've worked and how you went about changing the application.

Carefully read the instructions before you proceed.

## Scope

There are many things that you could do to improve the code, but we want to add the following functionality in the future, so this may affect your choices:

* We need to ensure that our API works and that we do not introduce errors.
* We will want to deploy this API, so make sure it is production-ready.
* Keeping the data in a JSON file is fine, but we will want the ability to use something more flexible in the future.
  * We might want to use a different data store next to the JSON file.
* We will want to fetch a single Pet from its own API endpoint which may contain additional data than is in the listing endpoint.
* We will want to add APIs for the other CRUD operations upon a Pet.

## Submitting

There are two ways you can submit your assignment:

1. Through a **private** GitHub repository
   1. Ensure you invite both interviewers for this repository
2. Through a zip archive over email
   1. Ensure you _include_ your `.git` folder
   2. Ensure you _exclude_ your `node_modules` folder
   3. Ensure you email it to both interviewers and the recruiter

Your assignment should be submitted at least 2 working days before your interview.
This allows the interviewers to review your assignment, prior to the interview.

## Interview

An appointment will be made to talk to you about your assignment.
During this one-hour interview two Coolblue developers will ask you to explain the choices you made
and answer questions about the assignment and web development in general.
Please ensure you're able to screenshare your IDE in this meeting (through Google Meet).

Be aware, the interview will be done in English.

## Questions

- **Question**: How much time do I have? \
  **Answer**: We don't give you a time limit. If you only have a few hours to spare, take that, if you want to spend your weekend on it, go for it! We'd recommend you try to spend about 4 hours, we don't judge on the amount of time you spend, we want to know the reasons behind your decisions.
- **Question**: Can I use AI for this assignment? \
  **Answer**: Yes, you are allowed to use AI in any capacity. However, whether it is code you've written yourself or generated by AI, you will be questioned about it. We expect you to explain what the code is doing and why you went for this approach.

If you have any other questions while working on the exercise feel free to reach out. We will be happy to help.
