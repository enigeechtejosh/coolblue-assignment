# Pet API

> This service provides the API for storing and providing Pet data. \
> This service acts as a REST API and returns results in JSON.

## Prerequisites

Before you start working with this project,
make sure you have the following tools installed on your system:
- [nvm](https://github.com/nvm-sh/nvm)
- [node](https://nodejs.org/)
- [npm](https://www.npmjs.com/)

This application is build with the following dependencies:
- [express](https://expressjs.com/)
- [eslint](https://eslint.org/)
- [vitest](https://vitest.dev/)

## Getting started

### Development environment

To run the development build, follow these steps:
- Install the dependencies with `npm ci`
- Run the application in watch mode with `npm run dev`

### Production environment

To test the production build, follow these steps:
- Build the project with `npm run build`
- Serve the project with `npm run serve`
- Open the application at http://localhost:3000

## Project commands

| Command | Description                           |
|---------|---------------------------------------|
| build   | Create a production build             |
| serve   | Run the production build              |
| dev     | Run a development build in watch mode |
| test    | Run all tests                         |
| lint    | Run all linters                       |
